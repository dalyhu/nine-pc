# 第一部分：一页纸摘要（所有人）

## 解决了什么问题

| # | 问题 | 现在 |
|---|---|---|
| 1 | 用 **Safari 13.1 等旧浏览器**打开网站**白屏** | 能正常打开；浏览器确实太旧时显示「请升级浏览器」页面，不再白屏 |
| 2 | 网站**启动失败**（文件加载失败、卡住）时白屏 | 显示「页面加载失败」页面，可以刷新、复制诊断信息 |
| 3 | 某个页面**运行出错**时整块空白 | 只在内容区显示错误卡片，顶部导航还能用，可以返回首页 |
| 4 | 发新版后，用户开着的旧页面**点了没反应** | 自动刷新一次拿新版本；还不行就显示错误卡片 |
| 5 | 访问**不存在的地址**整页空白 | 显示新设计的 404 页，可以返回首页 |
| 6 | 以后开发**不小心用了旧浏览器不支持的写法**，没人发现 | 打包时自动检查，发现就打包失败，问题到不了线上 |
| 7 | 旧浏览器上 **PWA 离线功能**不生效 | 升级 PWA 库到 0.4.3 后恢复（离线页、更新提示条都可用） |
| 8 | 浏览器偏旧的用户没有升级引导 | 新增底部软性提示条，**默认关闭**，需要时改配置打开 |

**支持的最低浏览器**：Safari 13.1 / iOS 13.4 / Chrome 80 / Edge 80 / Firefox 74（都是 2020 年前后的版本）。

## 用户能看到的 4 处界面

### ① 404 页（访问不存在的地址时）


风格与站点的 406「禁止访问」页一致。「返回首页」回到首页。

### ② 兜底页（浏览器太旧，或网站启动失败时）


- **版本过低**：显示当前浏览器版本和本站支持的版本，推荐下载 Chrome。
- **页面加载失败**（启动 10～20 秒仍空白，或页面整体渲染失败）：语气轻，只说「页面没有加载出来，可能是网络不太稳定，刷新一下就好」，给「刷新页面」和「复制诊断信息」，不推荐换浏览器；页面加载出来后会自动关闭。
- 「复制诊断信息」方便发给客服，包含浏览器信息和最近的报错，会自动隐去 token 等敏感信息。

### ③ 页面级错误卡片（某个页面运行出错时）


顶部导航保留；提供「刷新页面」「返回首页」「复制诊断信息」。发版后页面文件加载失败、自动刷新也没解决时，显示的也是它。

### ④ 软性升级提示条（**默认关闭**，打开后才出现）


浏览器能用但偏旧时（Chrome/Edge/Firefox 比最新版落后 4 个版本以上，Safari 不是最近 2 个大版本），在页面底部居中提示。8 秒自动消失，点 × 后 7 天内不再出现，只在电脑上显示。

## 风险结论

| 方面 | 结论 |
|---|---|
| 原有页面和功能 | **基本不受影响**。原有业务代码只改了 2 个文件：`404.vue`，以及 `operationPanel` 里加了一行注释。其余都是新增文件，或在入口文件里接入新组件。线上、pre 两个环境改动前后逐项对比一致 |
| 页面加载 | 每个访问者多加载一个约 **40 KB（压缩后）**的兼容补丁文件，换来旧浏览器能打开 |
| 打包流程 | `pnpm build` 多了两道检查，**会让打包失败**，时间约多 5 秒。现有代码检查结果为 0 个问题 |
| 线上配置 | 新增的提示条开关默认关闭，对线上没有影响 |
| 需要运维配合 | 两处，见第二部分「上线注意事项」 |

### 3.2 打包命令 `pnpm build`

```
改动前：vite build --mode prod
改动后：源码兼容检查 → vite build --mode prod → 产物兼容检查
```

- 两道检查任何一道发现问题都会**让打包失败**，CI 也会跟着失败。
- 检查不过时，先改代码。确实是误报的话，在那一行加忽略注释并写明原因，参考 `operationPanel/index.vue`。
- 紧急开关 `X9_SKIP_COMPAT_CHECK=1` 可以跳过检查，**AI 和日常开发不得使用**。目前 CI 的 Docker 构建不会把这个变量传进容器，在 CI 里设了也不生效（已决定暂不改）。

## 4. 上线注意事项（运维）

1. **CSP 响应头**：PWA 离线页的内联脚本和样式哈希会变。如果线上 nginx 或网关配了 CSP，需要同步更新。仓库里没有 CSP 配置，需要运维确认。
2. **PWA 后台脚本更新**：`sw.js` 内容变了，老用户下次访问时浏览器会自动更新，可能看到一次右下角的「有新版本」提示，属于正常现象。
3. **紧急开关在 CI 里不生效**：见 3.2。
4. **`public/404.html`**（标题「服务维护中」）：这次**没动**。它不是路由的 404 页，线上什么时候显示它取决于 nginx 配置，需要运维确认用途。
